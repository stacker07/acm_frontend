# OmniForge Dashboard

A beautifully designed, purely static (HTML/CSS/Vanilla JS) dashboard experience showcasing **OmniForge**, an autonomous multimodal self-healing developer engine.

## 🚀 Features

* **Glassmorphic UI**: Sleek, modern design using CSS `backdrop-filter`, subtle noise layers, and translucent panels.
* **Agent Pipeline Stepper**: A vertical interactive timeline that simulates 4 stages of development (Architect, Sandbox, Vision Sentry, Convergence).
* **Live Terminal Simulation**: An animated CRT-style terminal with color-coded syntax and realistic typing effects for command ingestion and execution logs.
* **Dynamic File Explorer**: Visual representation of project scaffolding as the simulated "Architect" generates files.
* **Auto-Heal Simulation**: Simulates catching a runtime exception (TypeError) and automatically hot-patching the code.
* **Interactive Visual PR**: A before/after draggable slider comparing a broken DOM render against a flawlessly repaired one, alongside code diffs.
* **Zero Dependencies**: Built entirely with Vanilla JS and CSS in a single `index.html` file—no WebGL, no React, no external libraries.

## 🛠️ Usage

Since this is a self-contained static file, simply open it in your browser!

1. Clone or download the repository.
2. Double click `index.html` (or serve it with a local server like `python3 -m http.server 8080`).
3. Enter a prompt into the top command bar.
4. Click **IGNITE & DISPATCH** to watch the AI simulation run its course.

## 🎨 Design System

* **Typography**: *Inter* for standard UI, *JetBrains Mono* for code/terminal outputs, and *Outfit* for stylized headers.
* **Colors**: Deep space backgrounds with vibrant neon accents (Cyan, Emerald, Violet, Amber, Crimson).
* **Grid Architecture**: Fully responsive CSS Grid separating the Command Header, Sidebar Stepper, and Main Terminal Workspace.
